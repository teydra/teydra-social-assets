# Teydra Social Assets

Public image host for social APIs that require fetchable media URLs, especially Instagram.

Only commit assets that are intended or approved to be public:

- approved social post images
- approved public brand assets
- approved public person images

Never commit internal screenshots, private documents, secrets, rough drafts, or non-approved person images.

Standard public URL base:

```text
https://raw.githubusercontent.com/teydra/teydra-social-assets/main
```
